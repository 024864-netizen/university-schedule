\# Лабораторна робота №3



\## Тема

Стилізація: блокова модель, Flexbox і Grid.



\## Мета

Створити адаптивний інтерфейс за допомогою CSS Grid і Flexbox та стилізувати форму зворотного зв'язку.



\## Виконання



Для всіх сторінок підключено спільний файл `styles.css`. Основна структура сторінки створена за допомогою CSS Grid з областями `header`, `main`, `sidebar` і `footer`.



Для шапки та навігації використано Flexbox: елементи вирівнюються по вертикалі та розподіляються по ширині.



На головній сторінці створено сітку карток за допомогою `auto-fit` і `minmax()`. Кількість колонок автоматично змінюється залежно від ширини екрана. Кнопки карток вирівняні внизу за допомогою `margin-top: auto`.



Форму з лабораторної роботи №2 стилізовано за допомогою CSS. Додано focus-стан, error-стан через `:invalid` та мінімальну висоту елементів 44px.



Для адаптивності використано media queries. При ширині близько 400px картки розташовуються одна під одною, а sidebar переходить під основний контент.



У CSS не використовуються inline-стилі та `!important`. Для повторюваних значень використано CSS-змінні.



Під час перевірки каскаду в DevTools видно, що правило `button:hover` змінює фоновий колір кнопки порівняно з базовим правилом `button`.
