### 6. Перевірка індексу та обмежень

Виконано `EXPLAIN` для запиту з індексом та без нього.

- З індексом: `type = ref`, `key = idx_disciplines_semester`, `rows = 3`.
- Без індексу: `type = ALL`, `key = NULL`, `rows = 14`.

Перевірено обмеження `UNIQUE`: повторне додавання коду `UI901` відхилено з помилкою `#1062`.

Перевірено обмеження `CHECK`: додавання запису з `credits = 0` відхилено з помилкою `#4025`.

### 7. Висновок

У ході лабораторної роботи створено базу даних MariaDB, налаштовано підключення через пул з'єднань, реалізовано CRUD-операції та інтеграцію frontend із backend.

Перевірено збереження даних після перезавантаження сторінки, роботу індексу та обмежень цілісності даних.
