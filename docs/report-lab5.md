\#Лабораторна робота №5



\## Тема

JavaScript та DOM-інтерактивність вебзастосунку.



\## Мета роботи

Додати до вебзастосунку інтерактивність за допомогою JavaScript, роботу з DOM, пошук і фільтрацію даних, модальне вікно, перемикання теми та завантаження даних через Fetch API.



\## Виконані завдання

1.Підключення JavaScript

JavaScript підключено до HTML-сторінок через файл `script.js` з атрибутом `defer`.



2\. Перемикання теми

Реалізовано перемикання між світлою та темною темами. Вибір теми зберігається у `localStorage`. При першому відкритті використовується системна тема користувача.



3.Пошук та фільтрація

Реалізовано пошук без перезавантаження сторінки та фільтрацію карток за категоріями. При зміні пошукового запиту або категорії список карток оновлюється динамічно.



4\. Модальне вікно

При натисканні кнопки «Детальніше» відкривається модальне вікно з інформацією про вибраний запис.



Модальне вікно можна закрити кнопкою «Закрити», клавішею `Escape` або натисканням поза межами вікна. Після закриття фокус повертається на кнопку, яка відкрила модальне вікно.



5.. Завантаження даних через Fetch API

Дані карток завантажуються з файлу `data.json` за допомогою `fetch()`.



Передбачено стан завантаження, перевірку `response.ok`, обробку помилки, кнопку «Повторити» та повідомлення про відсутність результатів пошуку.



\###6.Делегування подій

Для карток використано делегування подій. Один обробник події `click` встановлено на контейнер `.cards`.



Фрагмент коду:



```js

cardsContainer.addEventListener("click", (event) => {

&#x20;   const button = event.target.closest("button\[data-id]");



&#x20;   if (!button) {

&#x20;       return;

&#x20;   }



&#x20;   const record = records.find(

&#x20;       (item) => String(item.id) === button.dataset.id

&#x20;   );



&#x20;   if (record) {

&#x20;       openModal(record, button);

&#x20;   }

});

Такий підхід дозволяє не створювати окремий обробник для кожної картки



7\. Безпечна робота з DOM

Для виведення зовнішніх даних використано textContent та створення DOM-елементів через JavaScript. innerHTML для зовнішніх даних не використовується.

Обробка помилок

Під час завантаження data.json використовується конструкція try...catch.

Якщо файл недоступний або сервер повертає помилку, користувач бачить повідомлення «Не вдалося завантажити дані. Спробуйте ще раз.» та кнопку «Повторити».

Також реалізовано повідомлення «За вашим запитом нічого не знайдено.» для випадку, коли пошук або фільтрація не дають результатів.
